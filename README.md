# ROYAL-BAKERY-KVSAS-INVENTORY
Aplikasi Inventory Bahan Bakeri merupakan sistem pengurusan stok digital yang dibangunkan bagi memudahkan pengurusan bahan mentah di bengkel bakeri dan pastri. Aplikasi ini membolehkan pengguna merekod, mengemas kini dan memantau kuantiti stok bahan secara sistematik dan teratur.
